# Project Portfolio PPTX

컨설팅(Deloitte / PwC / Accenture) 톤의 금융 IT 경력직 제출용 포트폴리오.

## Generate

```bash
cd tools/portfolio-pptx
npm install
npm run build
```

출력:

- `dist/YYYYMMDD_최지웅_Project_Portfolio_v1.0.pptx`
- `D:\개인\02_Career\1. Resume\` 로 복사 시도

## Design

- White / Navy / Gray
- Pretendard (시스템에 설치되어 있어야 PowerPoint에서 동일하게 보임)
- 9 slides: Cover → About → Career → Skills → PJ01 → PJ02 → Achievements → Strength → Thank You
