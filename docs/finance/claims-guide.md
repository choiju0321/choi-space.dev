# Claims 가이드

Ledger **의료** 지출이 Claims에 **월별**로 자동으로 보인다.  
기본 상태는 **미신청**. 청구했는지·환급받았는지만 체크한다.

## 상태

`미신청` → `신청` → `환급완료` (또는 `반려`)  
약국만 간 건처럼 청구 안 할 항목은 `제외`

## 흐름

1. 월말 뱅크샐러드 → Ledger Import (의료 지출 포함)
2. Claims에 의료 건이 **미신청**으로 목록에 뜸
3. KB 앱에서 청구 후, 목록에서 **신청** 버튼
4. 환급되면 **환급완료**
5. 약국만 등 청구 안 할 건 **제외**

사진·서류는 **KB 앱에만**. 여기 첨부는 필수가 아님.  
상세 메모가 필요하면 Edit(선택).

## 타이밍

병원 직후에는 Ledger에 없을 수 있다. Import 후에야 Claims에 나타난다.
