# Property 가이드

이사 **할 일**을 WBS로 나누고, Due·간트로 일정을 본다.  
예산(비용관리)·청약 공고는 다음.

## 카테고리 (WBS)

`1` 계약·예약 → `1.1` 할 일 · `1.2` 할 일 …  
날짜(D-구간)는 WBS가 아니라 일정 메타.

1. 계약·예약  
2. 구매·준비  
3. 퇴실 정산  
4. 이사 당일  
5. 입주 및 설치  
6. 행정 처리  
7. 마무리 

## 작성 (Write)

- **Category** + **Index(WBS 순번)** → `1.1`  
- **Due date**만 관리  
- Window / Window order 없음 → 일정 구간은 **간트 모달**에서 저장

## 보기

| 탭 | 역할 |
|----|------|
| **카테고리** | WBS(`1` → `1.1`)로 체크 |
| **간트** | D-30~D+30을 **한 화면 폭**에 압축 · 행 클릭 시 모달 |

연한 막대 = 예전 D-제안(있으면) · 진한 막대 = Due/간트 저장 일정.

## 흐름

1. `/finance/property` · 독산역 롯데캐슬  
2. 남은 일 필터에서 할일→진행→완료  
3. 간트 탭으로 전체 일정 확인
