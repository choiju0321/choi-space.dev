# Property 가이드

이사 **할 일**을 WBS로 나누고, Due·간트로 일정을 본다.  
예산(비용관리)·청약 공고는 다음.

## 카테고리 (WBS 트리)

`1` 계약·예약 → `1.1` 할 일 → `1.1.1` 하위 → `1.1.1.1` … **무한 깊이**.  
번호는 상위를 고르면 위치에 따라 **자동으로 매겨진다**(직접 입력 없음).  
날짜(D-구간)는 WBS가 아니라 일정 메타.

최상위 카테고리(레벨1)는 **케이스마다 자유롭게 추가·수정·정렬·삭제**한다.  
새 케이스는 아래 이사 표준 7개로 시작한다 (Property 화면 하단 **"카테고리 관리"**):

1. 계약·예약  
2. 구매·준비  
3. 퇴실 정산  
4. 이사 당일  
5. 입주 및 설치  
6. 행정 처리  
7. 마무리 

- 순서가 곧 WBS 번호(1·2·3…) — 위/아래 버튼으로 재정렬  
- 할 일이 든 카테고리는 **비워야 삭제** 가능 (최소 1개 유지)  
- 다른 종류의 일도 이 카테고리 구조로 WBS 관리 가능

## 작성 (Write)

- **상위(Parent)** 선택 → 그 아래로 붙고 WBS 번호 자동 (`1.1`, `1.1.1` …)  
  - 최상위 카테고리 바로 아래로 넣거나, 기존 할 일의 하위로 넣는다.  
- **Due date**만 관리  
- 자식이 생기면 상위 상태는 **하위 진행률(리프 기준 %)로 자동 계산** — 상위엔 상태 버튼이 없다.  
- 삭제는 **하위까지 함께**(확인 후) 지워진다.  
- 간트 일정은 **자동** — 날짜를 직접 고르지 않는다. (막대 = 진행 상태 + Due Date)

## 보기

| 탭 | 역할 |
|----|------|
| **카테고리** | WBS 트리(`1` → `1.1` → `1.1.1`)로 체크·진행률 |
| **간트** | D-30~D+30을 **한 화면 폭**에 압축 (읽기 전용, 자동 색칠) |

**간트 막대는 상태·Due Date로 자동 계산**:

- **진행(doing)** → "진행"을 누른 날(`startedAt`, 자동 기록) ~ **Due Date** · 진한 막대  
- **완료(done)** → 시작 ~ Due · 회색 막대  
- **할일(todo) + Due** → **오늘 ~ Due** 예정 막대(옅게)  
- Due·상태가 없으면 레거시 `window` D-구간이 있을 때만 표시

## 흐름

1. `/finance/property` · 독산역 롯데캐슬  
2. 남은 일 필터에서 할일→진행→완료  
3. 간트 탭으로 전체 일정 확인
