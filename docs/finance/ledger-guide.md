# Ledger 분류 가이드

뱅크샐러드 Import 후 **대분류·소분류·메모(#태그)** 를 이 규칙으로 맞춘다.  
소비 패턴은 비슷하니, 카테고리를 늘리기보다 **같은 바구니에 넣는 습관**이 우선이다.

기준 데이터: 2026-04 ~ (태그 작업 시작 이후)

---

## 1. 타입 (뱅크샐러드 그대로)

| 타입 | 쓸 때 |
|------|--------|
| **지출** | 카드·페이로 나간 소비 |
| **수입** | 급여·용돈·환급·배당·중고 판매 입금 |
| **이체** | 계좌 이동 · 현금 인출 · 카드대금 · 월세 이체 · 개인 송금 |

> 같은 월세라도 카드면 지출, 계좌이체면 이체 — **타입은 결제 수단을 따르고**, 카테고리로 목적을 맞춘다.

---

## 2. 대분류 (권장 세트)

### 소비 (지출)

| 대분류 | 넣는 것 | 소분류 예 | 메모 태그 예 |
|--------|---------|-----------|--------------|
| **식비** | 외식·배달·베이커리 | 점심 / 저녁 / 배달 / 베이커리 | `#점심` `#냉모밀` |
| **카페** | 커피·디저트 매장 | (비워도 됨) | `#아아` |
| **편의점** | CU·GS·세븐 등 | | `#단백질쉐이크` |
| **생필품** | 쿠팡·마트·생활용품 | 쿠팡 / 마트 | `#샐러드` |
| **교통비** | 버스·지하철·택시·주차·철도수수료 | 교통카드 / 택시 / 수수료 | `#지하철` |
| **주거** | 월세·관리·가스·전기·수도·대출이자·부동산 행정 | 월세 / 가스비 / 전기요금 / 계약금 / 행정 | `#월세` |
| **통신비** | 통신·인터넷 묶음 청구 | | `#통신비` (넷플 포함이어도 통신비 유지) |
| **의료** | 병원·약국·실손 관련 | 병원 / 약국 / 환급 | `#치과` |
| **쇼핑** | 물건·굿즈·중고 구매 | 중고 | `#당근` `#굿즈` |
| **여가** | 웹소설·게임·영화·케어 | 웹소설 / 게임 / 구독 / 영화 | `#네이버시리즈` `#클래시로얄` |
| **자기개발** | 책·AI/생산성 구독 | 도서 / AI구독 | `#교보` `#커서` `#챗지피티` |
| **데이트** | **목적이 데이트일 때** (식비·카페보다 우선) | | `#재윤` `#예약금` |
| **여행** | 여행 중 교통·숙소·입장 | 숙소 / 교통비 / 관광 | `#춘천` `#itx` |
| **기부/후원** | 정기·일시 후원 | | `#밀알` |
| **보험** | 보험료 (환급 입금도 여기) | | `#실손` |
| **기타** | 행정 수수료 등 애매한 1회성 | 행정 | |

### 수입

| 대분류 | 넣는 것 |
|--------|---------|
| **급여** | 급여·복리후생 |
| **용돈** | 가족 용돈 입금 |
| **금융수입** | 배당·이자(급여성) |
| **기타수입** | 세금 환급·중고 판매 입금 |

### 이동 (이체) — 소비 합계에서 빼 두고 볼 것

| 대분류 | 넣는 것 |
|--------|---------|
| **내계좌이체** | 내 계좌끼리 (애매할 때만) |
| **카드대금** | 카드 결제 출금 |
| **저축** | 적금·퇴직연금·청약 |
| **투자** | 증권 이체·통장 이자 | 소분류: 증권 / 이자 |
| **현금인출** | ATM·지갑 | `#현금인출` |
| **이체** | 개인 송금 (용돈 드림 등) | 소분류: 용돈 / 개인 |

## 3. 메모(#태그) 규칙

1. **대분류로 못 담는 디테일만** 태그에 둔다. (`#장어초밥`, `#아아`)
2. 사람·장소·목적이 중요하면 태그. (`#김대준`, `#독산역롯데캐슬`)
3. 한 줄에 `#태그` 위주. 쉼표로 메뉴만 나열해도 됨.
4. 뱅크샐러드 상호명(`토스페이_일반`)은 고쳐도 되고, **태그가 진실**이다.

### 지출 세부 조회 (Ledger 칩)

| 칩 | 판별 |
|----|------|
| **웹소설** | `#네이버시리즈` `#노벨피아` `#카카오페이지` (소분류 `웹소설`) |
| **게임** | `#클래시로얄` `#66666년…` 등 (소분류 `게임`) |
| **구독료** | Cursor·ChatGPT·여가 구독 (`#구독료`, 소분류 `구독`/`AI구독`) — 웹소설·게임 제외 |
| **커피(전체)** | 대분류 `카페` |
| **커피·혼자** | 카페 + `#혼자` |
| **커피·같이** | 카페 + `#같이` |
| **식사(전체)** | 대분류 `식비` 전부 |
| **식사·혼자** | 식비 + `#혼자` |
| **식사·같이** | 식비 + `#같이` (동행 이름 있어도 됨) |

**식사·커피 태그 (앞으로)**  
- 혼자 결제 → `#혼자`  
- 같이 먹고/마시고 결제 → `#같이` (+ 동행 이름 있으면 더 좋음)  
예전에 쓰던 `#약속`/`#일상`도 같이/혼자로 읽히게 남겨 둠.  
중간중간 안 맞는 건 Ledger 행 **Edit**으로 대분류·소분류·메모만 고치면 됨. 칩은 태그를 믿을게.

## 4. 헷갈릴 때 (우선순위)

1. **데이트**인가? → 식비/카페/쇼핑 대신 `데이트`
2. **여행 중**인가? → `여행` (평소 교통과 분리)
3. **AI·책·강의**인가? → `자기개발` (웹툰·영화는 `여가`)
4. **월세·공과금**인가? → 타입이 이체여도 대분류는 `주거`
5. **카드대금·저축·증권 이동**인가? → 소비로 보지 말고 이동 카테고리
6. 그래도 애매하면 → 큰 바구니(`식비`/`생필품`/`쇼핑`) + 태그만 정확히

### 쓰지 말 것

- `현금` (바구니) — 목적 카테고리로 풀기
- `생활비-고정` / `생활비-변동` — `통신비`·`식비` 등으로
- `미분류` 소분류 — 비우거나 구체 소분류
- `여가활동` — `여가`로 통일

---

## 5. 월간으로 볼 때

- **소비 합** ≈ 식비+카페+편의점+생필품+교통+쇼핑+여가+자기개발+데이트+여행+의료+통신+기부 (+주거 중 카드 지출)
- **이동** (카드대금·저축·투자·현금인출·내계좌)는 소비와 **따로** 본다
- 통신 청구에 넷플이 묶여 있어도 대분류는 `통신비` 유지, 태그에 `#넷플` 정도만

생필품 소분류: `식자재` · `생활용품` (쿠팡/마트는 태그 또는 보조 소분류)  
여가 소분류: `웹소설` · `게임` · `소개팅앱` · `구독` … (앱 이름은 `#태그`)
