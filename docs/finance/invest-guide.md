# Invest 가이드

주식·연금은 **매매 장부가 아니라 월 1회 보유 스냅샷**으로 관리한다.

## 역할 분담

| | Ledger | Invest |
|--|--------|--------|
| 무엇 | 돈의 **이동** (이체·적립) | 그 결과 **잔고 사진** |
| 예 | `투자` · `저축` · 증권 이체 | 토스증권 평가액 · IRP 평가액 |
| 주기 | 뱅크샐러드 Import | 월말 Write |

## 한 달에 할 일

1. 증권·연금 앱에서 계좌별 **평가액**(원금 있으면 같이) 확인  
2. `/finance/invest` → **Write**  
3. Kind: 주식 / 연금 · Account · Valuation · (Cost basis 선택)

같은 계좌는 매월 새 스냅샷을 남긴다. Edit은 그달 숫자 수정용.

## 일부러 안 하는 것

- 전 종목 매매 Import  
- 실시간 시세  
- 세무·실현손익 장부
