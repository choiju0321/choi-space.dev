# 01 · Brand

## 한 줄

Choi Space는 **포트폴리오가 아니라 Personal Archive**다.  
소개로 사람을 요약하지 않고, **기록으로 사람을 보여준다.**

## 슬로건 (불변)

```text
소개는 한 페이지지만,
기록은 한 사람을 보여줍니다.
```

이 문장은 사이트 전체를 관통한다. Home manifesto, 메타 설명, 문서에서 같은 뜻을 유지한다.  
**슬로건 문구 자체는 바꾸지 않는다.** (표현·배치만 evolve)

## 키워드

| 키워드 | 의미 |
|--------|------|
| **기록** | 결과보다 과정이 남는다 |
| **성장** | 배운 것을 내 말로 정리한다 |
| **경험** | 책·러닝·문화·일상 |
| **공유** | 다시 찾을 정보를 담백하게 연다 |
| **꾸준함** | 한 번의 화려한 페이지보다 쌓임 |

## 목표 포지션

| 아니다 | 이다 |
|--------|------|
| Developer Portfolio | Premium Personal Website |
| 흔한 블로그 테마 | Personal Archive |
| 이력서 대체 랜딩 | 브랜드 경험 |

## 톤

- 차분함 (Calm)
- 절제 (Minimal)
- 완성도 (Premium / Luxury without glitter)
- 읽기 편함 (Readable)

## 참고하되 복사하지 말 것

Apple · Linear · Notion · Vercel · Stripe · Raycast · Medium · Arc  

공통점만 취한다: **타이포 우선, 여백, 장식 최소화, 모션은 존재감 없음.**  
레이아웃·일러스트·그라데이션을 베끼지 않는다.

## 금지 인상

- “AI가 만든 홈페이지”
- 흔한 Hero + 카드 3개 + CTA 버튼 덩어리
- 과한 그라데이션 / 글로우 / 퍼플 테마
- 포트폴리오 템플릿 구조 (스킬 바, 통계 스트립 등)
