# 07 · Writing Style

## 톤

짧고, 담백하고, 읽기 쉽게.  
마케팅 과장·감탄사 남발·허세 금지.

## 한다

- 한 문장에 한 생각
- 구체적 명사 (책, 러닝, 기록)
- 차분한 경어/평서 (페이지에 맞게 일관)
- 슬로건·철학은 정해진 문장 유지

## 하지 않는다

- “최고의”, “혁신적인”, “올인원” 같은 빈 수식
- 이모지로 감정 대체
- 긴 히어로 에세이 (Home)
- 영문 슬로건을 어색하게 직역해 두 번 쓰기

## 영역별

| 영역 | 문장 역할 |
|------|-----------|
| Home Hero | 브랜드 + 한 줄 |
| Manifesto | 슬로건만 |
| About | 사람 한 호흡 + Profile로 위임 |
| Life/Growth/Notes | 공간 안내, 글 본문은 각 아카이브에서 |
| Empty | 사실만 (“곧…”) |

## 언어

- 내비·섹션 라벨: **English** (About, Life, Growth…)
- 설명 문장: **한국어** 담백체
- 혼용 시 한 문장 안에서 한글로 통일하는 편이 읽기 쉬움
