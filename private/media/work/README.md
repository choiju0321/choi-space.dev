# Work media

프로젝트·시즌 **증거 파일**만. 본문(경험·성과)은 콘텐츠 JSON.

```text
src/content/work/{companySlug}/projects.json   ← Write로 생성·수정
private/media/work/{companySlug}/{slug}/       ← 첨부 증거
```

- Work UI = 경험 원장 (Projects · Seasons · Etc)
- Write = `/write?category=work&company=…`
- 원본 아카이브: `D:\개인\01_Work\` (전부 미러링하지 않음)
- 급여·재직 = Documents
